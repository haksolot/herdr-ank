La frontière avec herdr (ADR-357c017baf9b). Le binaire factice de test est un petit
script écrit par le test lui-même dans un tempdir, qui copie son argv dans
un fichier ; `HERDR_BIN_PATH` pointe dessus.

Les commandes réelles, telles que `herdr <domaine>` les documente en 0.9.1 :
- `pane report-metadata <pane_id> --source ID --token NAME=VALUE --clear-token NAME --ttl-ms N`
- `notification show <title> --body TEXT --sound none|done|request`
- `worktree create --workspace ID --branch NAME --base REF --path PATH --label TEXT --no-focus`
- `tab create --workspace ID --cwd PATH --env KEY=VALUE --label TEXT --focus`
- `agent start <name> --kind KIND --pane ID`
- `agent prompt <target> <text>`
- `pane list --workspace ID`, `agent list`
Le socket : `{"id":"sub_1","method":"events.subscribe","params":{"subscriptions":[{"type":"pane.agent_status_changed"}]}}`
puis un événement par ligne. Protocole 22 ; ignorer les champs inconnus.
