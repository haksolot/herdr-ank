  `herdr-plugin.toml` déclare `[[build]] command = ["sh", "install.sh"]` et toutes ses autres commandes pointent sur `./bin/herdr-ank`. `install.sh` (POSIX sh, `set -eu`, curl ou wget) lit `version` dans le manifeste, choisit la cible parmi x86_64-unknown-linux-musl, aarch64-unknown-linux-musl, x86_64-apple-darwin, aarch64-apple-darwin d'après `uname -sm`, télécharge `herdr-ank-<version>-<cible>.tar.gz` et `SHA256SUMS` depuis `https://github.com/haksolot/herdr-ank/releases/download/v<version>/` (base remplaçable par la variable HERDR_ANK_RELEASE_BASE, qui accepte une URL file://), vérifie la somme avec sha256sum ou shasum -a 256, extrait le binaire dans `./bin/herdr-ank` exécutable. Le README dit ce que l'installation télécharge et quand cargo sert.

Applique ADR-7aab39e2dbd8. Le script est le seul code hors Rust du dépôt : le
garder court, sans bashisme, testé par le harnais cargo comme le reste.

Le test avec cargo présent ou absent se fait en construisant un PATH réduit
pour le processus enfant ; ne jamais désinstaller quoi que ce soit.

Une release doit exister pour qu'un utilisateur reçoive le binaire ; tant
qu'elle n'existe pas, le repli cargo est le chemin réel, et c'est voulu.
