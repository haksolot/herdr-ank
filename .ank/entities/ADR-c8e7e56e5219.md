Le token affiché dans la sidebar doit suivre le claim : pris, renouvelé,
relâché, expiré, ou fini sur une autre branche. Aucune de ces transitions n'est
un événement herdr. Les événements herdr disent quand une pane, un agent ou un
worktree apparaît ou change d'état, c'est-à-dire quand le mapping claim → pane
peut changer ; le poll rattrape ce qui bouge côté refs sans que herdr le voie.

`ank watch` est optionnel par conception (« nothing depends on it ») et
n'écrit que `events.jsonl`, une ligne par changement de corpus, sans dire quoi
faire. Le tail est donc un accélérateur : plus réactif quand l'utilisateur a
déclaré ses corpora, silencieux sinon.

La borne d'une synchronisation par seconde protège le corpus : chaque verbe de
lecture peut réindexer l'index SQLite jetable, et vingt pollers sur un arbre
sont exactement ce que docs/integrating.md déconseille.
