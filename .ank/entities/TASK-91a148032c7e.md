Le process long du plugin. `HERDR_PLUGIN_EVENT=startup` est posé par herdr
quand il le lance, après restauration de session, socket prêt.

Journal : stderr uniquement, une ligne par synchronisation avec le nombre de
rapports envoyés ; `herdr plugin log list --plugin ank` le relit.

Le tail de events.jsonl est un `notify` ou un poll de taille de fichier
toutes les secondes, au choix de l'exécutant ; la ligne lue n'est pas
interprétée au-delà de « le corpus a bougé ».
