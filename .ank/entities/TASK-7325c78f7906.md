## Pourquoi

Mesuré le 2026-09-27 sur omarchy (herdr 0.9.1, plugin 0.2.4 installé depuis
GitHub) : le daemon tourne, les tokens arrivent, open et work marchent, mais le
config.toml n'a aucun bloc ank, faute d'avoir lancé herdr-ank setup à la main.
Sans raccourci ni lignes de sidebar, l'utilisateur conclut que le plugin ne
marche pas. herdr-ank setup lancé sur une copie de ce config.toml (prefix =
"ctrl+space") a écrit les trois blocs et herdr config check les a acceptés.

## Choix (ADR-2df1)

- Au premier démarrage du daemon, pas dans le [[build]] : celui-ci n'a ni
  HERDR_BIN_PATH ni serveur.
- Une fois, par marqueur dans le state dir, comme la bienvenue (welcome() dans
  src/daemon/mod.rs) mais un marqueur distinct : les installations qui ont déjà
  été accueillies reçoivent quand même le setup.
- Ce qui n'est pas écrit est notifié ; le daemon ne s'arrête pas.

## Prefix

"prefix+a" est déjà relatif au prefix configuré (herdr --default-config :
"prefix+n requires the prefix"). Il reste à : ne rien écrire de littéral,
reconnaître "prefix+a" dans une liaison en tableau (key_binding ne lit
aujourd'hui que les chaînes, alors que le config.toml mesuré lie ses actions par
tableaux), et retirer « ctrl+b a » du README.
